## Was ist n8n?

n8n (pronounced "nodemation") ist eine Open-Source-Workflow-Automatisierungsplattform. Sie ermöglicht es, verschiedene Apps, APIs und Dienste miteinander zu verbinden — ohne Code oder mit minimalem Code.

Im Gegensatz zu Zapier oder Make kann n8n auf deinem eigenen Server gehostet werden. Das bedeutet: Volle Datenkontrolle, keine monatlichen Gebühr für Self-Hosting und unbegrenzte Workflows.

## Preise und Pläne

**Self-Hosting (kostenlos)**: n8n ist Open Source. Du kannst es auf deinem eigenen Server installieren — kostenlos, unbegrenzt.

**Cloud Starter** (20 €/Monat): 5 aktive Workflows, 2.500 Ausführungen/Monat.

**Cloud Pro** (50 €/Monat): 50 aktive Workflows, 10.000 Ausführungen/Monat, Team-Features.

**Enterprise**: Individuelle Preise, SSO, Support, SLA.

## Stärken von n8n

**Open Source**: n8n ist vollständig Open Source. Du kannst es kostenlos hosten, modifizieren und erweitern.

**400+ Integrationen**: Von Google Sheets über Slack bis hin zu Datenbanken — n8n hat über 400 eingebaute Integrationen.

**KI-Integrationen**: n8n unterstützt OpenAI, Claude, lokale LLMs und andere KI-Tools direkt in Workflows.

**DSGVO-freundlich**: Durch Self-Hosting bleiben alle Daten auf deinem Server — ideal für DSGVO-sensitive Anwendungen.

**Code-Modus**: Für Entwickler gibt es die Möglichkeit, JavaScript/Python-Code direkt in Workflows einzubauen.

## Schwächen von n8n

**Lernkurve**: n8n ist technischer als Zapier. Für Nicht-Entwickler gibt es eine steile Lernkurve.

**Self-Hosting-Aufwand**: Wer n8n selbst hostet, muss sich um Server, Updates und Sicherheit kümmern.

**Cloud-Preise**: Die Cloud-Version ist für einfache Workflows teurer als Zapier.

## Fazit

n8n ist die beste Wahl für technisch versierte Nutzer und Unternehmen, die Kontrolle über ihre Daten wollen. Für DSGVO-sensitive Anwendungen und komplexe Workflows ist es Zapier und Make überlegen. Wer keine technischen Kenntnisse hat, sollte die Cloud-Version testen oder bei Zapier bleiben.
